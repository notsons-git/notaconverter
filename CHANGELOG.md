# Changelog

Все важные изменения проекта NotAconverter документируются в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/), проект следует [SemVer](https://semver.org/lang/ru/).

---

## [1.2.0] - 2026-11-09

### Добавлено
- **Кроссплатформенность (CI/CD):** Автоматическая сборка для **Windows**, **macOS** (`.dmg` / `.zip`) и **Linux** (`.tar.gz`) через GitHub Actions.
- **Новый установщик Windows:** Компактный инсталлятор `NotAconverter-Setup-1.2.0.exe` (18.2 МБ) с ярлыками и установкой без прав администратора.
- **Панель управления медиа (`MediaControlBar`):** Единый узел под холстом: воспроизведение, подгонка `FIT 3.0s`, скорость `1.0x / 2.0x` и замок пропорций.
- **Мгновенный первый кадр:** Декодирование 0-го кадра за ~30 мс без задержки предпросмотра.
- **Интегрированный переключатель Preview / Crop:** Удобная неоновая индикация прямо над холстом.

### Улучшено
- **Ускорение экспорта VP9:** Оптимизированы проходы сжатия без потери качества.
- **Дизайн Tactical Obsidian 2.0:** Чистая палитра глубокого обсидиана (`#0F120E`) и кибер-лайма (`#A6FF00`), удаление паразитных цветов ОС.
- **Рантайм macOS / Linux:** Автопоиск FFmpeg из Homebrew и нативное системное аудио уведомлений (`afplay` / `paplay`).

### Исправлено
- Устранён «фантомный кадр» при переключении с картинки на видео.

## [1.1.1] - 2026-10-28

### Исправлено
- Краш при добавлении файлов (`NameError: name 'QFont' is not defined`).
- Потокобезопасность кеширования кадров `FrameCache` (передача через Qt-сигналы).
- Защита от повреждённых и 0-байтовых файлов (`MediaProbe`).
- Устранено дублирование элементов очереди и коллизии ключей.

---

## [1.1.0] - 2026-10-27

### Добавлено
- Универсальный импорт видео (`MP4`, `MOV`, `MKV`, `WebM`), `GIF` и графики (`PNG`, `JPG`, `WebP`).
- Интерактивное кадрирование с сеткой третей и пресетами (`1:1 Square`, `Free Crop`, `4:3`, `16:9`).
- Временная шкала с точной нарезкой и кнопкой `FIT 3.0s`.
- Фоновый кадровый кеш в RAM для мгновенного скраббинга без задержек.
- Автоматический двухпроходный битрейт-кламп для гарантированного веса $\le 256\text{ КБ}$.
- Сохранение прозрачности (`yuva420p`, VP9).
- Инлайн-переименование карточек в очереди по клику.
- Процедурный синтез звукового сигнала без внешних аудиофайлов.
- Дизайн-система «Tactical Obsidian».

## [1.0.0] - 2026-09-07

### Добавлено
- Базовая конвертация PNG и GIF в формат WebM для Telegram.

- Первичная поддержка прозрачности для статичных изображений.
